## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
XML for Mojo: parse into your own structs (`from_xml[T]`), write them back (`to_xml`), stream big
documents record by record (`Records`), or walk a compact tree (`parse -> Doc`). Structs are
walked with Mojo's standard `reflection` module; no dependency beyond the standard library. Every gate run checks the
parser against CPython's expat on 4,030 generated, mutated and real documents. Library only,
Mojo 1.2.0, linux-64; `pixi install` and `-I src`, or the conda package from `recipe.yaml`.

## Highlights

- Builds on Mojo 1.2.0. v0.1.0 could not: its dependency emberserde 0.1.0 ships a file precompiled by Mojo 1.1.0 that 1.2.0 refuses.
- No third-party dependency: decoding and encoding are xmojo's own, over Mojo's standard `reflection` module.
- Same `from_xml[T]` / `to_xml` behaviour and the same modifiers (`Rename`, `RenameAll`, `Skip`, `Defaulted`, `Field[..., extra_names=...]`, `DenyUnknownFields`, `ArmName`), now imported from `xmojo`.

## Changes

### Changed
- **Breaking:** the modifiers import from `xmojo` instead of `emberserde`: `from xmojo import Rename, Skip, Defaulted, Field, RenameAll, RenamePolicy, DenyUnknownFields, ArmName`.
- **Breaking:** decode and encode errors are plain `Error` values with the same text as before (for example `missing field: id`, `xmojo: unknown element <extra>`), not emberserde's `DeserializationError` / `SerializationError`.
- Pin moves to Mojo 1.2.0 (`pixi.toml`, `recipe.yaml`, `pixi.lock`).
### Removed
- The emberserde dependency. A struct set up for EmberJson no longer decodes from XML through the shared framework; it still decodes through xmojo's own rules.

## Known limits

- Parsing 80k sibling elements is about 5% slower on Mojo 1.2.0 than on 1.1.0 (16.8 vs 17.7 ms, same session); the parser did not change.
- Only unit `Variant` arms, scalar `SIMD` fields and `String` map keys, as in v0.1.0.

## Upgrade / run

```
pixi install      # Mojo 1.2.0
```
