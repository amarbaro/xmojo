# Agents

Using xmojo from Mojo code: read `skills/xmojo/SKILL.md` (install, struct mapping, streaming,
traps) and its `references/`. Claude Code: `/plugin marketplace add amarbaro/xmojo`, then install
the `xmojo` plugin.

Changing xmojo: `pixi install`, then `pixi run gate` must stay green (unit tests, tool builds,
expat differential with a negative control, every runnable snippet in README.md and the skill).
Rules in CONTRIBUTING.md. Sources are `src/xmojo/`; `src/xmojo/html_entities.mojo` is generated by
`tools/gen_entities.py`. Keep probe files out of directories that hold a `.mojoc`: Mojo searches
the main file's directory before `-I src`.
